# Chaotic Order · The Growth Kitchen

A 64-second unofficial launch-system concept by Encore Studio for [@ChaoticorderNFT](https://x.com/ChaoticorderNFT). It shows four tools a launch crew would run for the 1,111 Head Chef License free mint, skinned in Chaotic Order's own art and kitchen language. This is a video of a concept, not a live product.
