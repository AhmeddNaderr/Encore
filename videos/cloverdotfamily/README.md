# Cloverheads · Same Roots

An unofficial Encore Studio game concept using Clover’s original portraits and Clover Valley artwork. One little light must visit all four different friends to bloom a shared root.

## Downloads

- [Main video — 42 seconds, 1920×1080, 60fps, 29.1 MB](https://github.com/AhmeddNaderr/Encore/raw/refs/heads/main/videos/cloverdotfamily/Cloverheads-Same-Roots-main.mp4)
- [Vertical video — 15 seconds, 1080×1920, 60fps, 10.0 MB](https://github.com/AhmeddNaderr/Encore/raw/refs/heads/main/videos/cloverdotfamily/Cloverheads-Same-Roots-15s.mp4)
- [Source package — playable prototype, original art, research and production files](https://github.com/AhmeddNaderr/Encore/raw/refs/heads/main/videos/cloverdotfamily/Cloverheads-Same-Roots-sources.zip)

Both MP4s contain H.264 video, stereo AAC audio and faststart metadata. Exact frame counts and full audio/video decoding were verified.

The source ZIP omits the two separately downloadable final videos and the upstream SoundFont binary to fit GitHub’s file limit. It includes the rendered music, effects, original character/world assets, fonts and licenses, research, art bible/reference board/palette, five scored concepts, storyboard, playable prototype, quality report and unsent DM copy. `ARCHIVE-CONTENTS.md` explains the exclusions and how to obtain the upstream instrument if recomposing the score.
