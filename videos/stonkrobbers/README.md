# StonkRobbers: Midnight Exchange

A 45-second unofficial animated game concept trailer by Encore Studio. This is a video, not a playable game.

- [Download the 1080p video](https://github.com/AhmeddNaderr/Encore/raw/refs/heads/main/videos/stonkrobbers/StonkRobbers-Encore.mp4)
- [Download the smaller 720p video](https://github.com/AhmeddNaderr/Encore/raw/refs/heads/main/videos/stonkrobbers/StonkRobbers-Encore-720p.mp4)

Both files contain H.264 video and stereo AAC audio.

Original character art: [@stonkrobbers on X](https://x.com/stonkrobbers). Includes generated environments and character animation adapted from the original art, a proposed heist mission, original synthesized music and effects, and Encore Studio branding.
