# YORI · COLOR CUT

An unofficial Encore Studio game concept for [YORI (@yoricolors)](https://x.com/yoricolors), "More than colors" on Aptos. Hit YORI's moves on the beat. Every hit hard-cuts the screen to a new flat colour, the way YORI's own videos are edited. Don't touch the blue kid's bait cards. Fill the MASK meter before the drop to tie on the oni mask for ×2. Then the colours start to lie: read the move, not the colour.

Every character pixel is YORI's own published art: frames from the two official X videos, the PFP and the banner wordmark. Nothing was AI-generated or redrawn. The music and sound effects are original.

## Play it

Download `YORI-Color-Cut-game.html` and open it in Chrome, Edge, Firefox or Safari, on desktop or phone. It needs no install and works offline.

| Action | Keyboard | Touch |
|---|---|---|
| ☝️ ONE card | ← / A / F | tap the left half |
| 👋 WAVE card | → / D / J | tap the right half |
| Blue card (bait) | don't press | don't tap |
| Start / replay | Space | tap |
| Watch a demo | P | — |
| Timing offset | [ and ] (±5 ms) | — |
| Results: copy share text / leaderboard | S / L | buttons |

The song runs 85 seconds with 229 notes: verse, bait, build, MASK ON drop, COLORS LIE, MASK ON finale. Accuracy ranks run from GRAYSCALE up to FULL COLOR and MORE THAN COLORS. The result card copies the look of YORI's own WL status card, and "YOUR CUT" turns your run into a colour barcode. The leaderboard is sample data. "Share" only copies text to your clipboard; nothing is posted.
